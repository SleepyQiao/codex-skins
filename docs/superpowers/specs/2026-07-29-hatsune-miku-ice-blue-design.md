# 初音未来•冰蓝皮肤设计

## 目标

在外部 `codex-skins` 仓库新增一个仅适配 Codex 浅色外壳的 Dream Skin，名称为“初音未来•冰蓝”。使用用户提供的初音未来冰蓝插画作为新任务主页背景。

## 包边界

- 包 ID：`hatsune-miku-ice-blue`。
- 新任务主页使用沉浸式背景；焦点偏右，左侧保留为输入框和建议卡的视觉安全区域。
- 聊天、工作和其他页面不使用人物插画，只继承冰蓝浅色的面板、描边、强调色和深色文本。
- 不修改共享运行时注入器，也不改变 Codex DOM、交互或布局。

## 资源与元数据

- 将用户提供的 PNG 转为包内 `background.jpg`，避免透明通道和格式兼容问题。
- `skin.json` 声明背景、主题和包内样式；`theme.json` 使用 `appearance: "light"`。
- 本次不生成 `thumb.jpg`，也不更新 README 画廊；缩略图可在后续单独补充。

## 视觉令牌

- 背景：淡冰蓝白色；面板：低不透明度白蓝；文字：深蓝灰。
- 强调色：青蓝；悬停强调色：更亮的湖蓝；边线：低对比冰蓝。
- 主题艺术安全区：`left`，焦点约为 `(0.76, 0.48)`，任务模式为 `ambient`。

## 验证

1. 结构检查：清单字段、文件路径和 JSON 可解析。
2. 应用检查：通过 macOS 启动脚本安装该外部包，并确认 Codex 读取到该主题。
3. 浅色壳截图检查：新任务主页可见插画且左侧控件可读；聊天页不出现全页人物背景，并保持浅色文本与面板对比度。
